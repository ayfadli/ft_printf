# ft_printf

## Description
One of the first projects after completing Libft in the 1337/42 School curriculum. You must write your own version of the printf function, handling various format specifiers and flags.

## About This Repository
This repository includes a Python script (`generate_readmes.py`) that can automatically generate README files for 1337 curriculum projects.

### Usage of README Generator

The `generate_readmes.py` script scans folders and generates appropriate README files based on project type:

- **C Projects**: Detects Makefiles and documents make rules
- **Python Projects**: Detects .py files and documents python3 usage
- **SysAdmin Projects**: For Born2BeRoot, lists LVM/SSH/UFW configurations

Run the script:
```bash
python3 generate_readmes.py [path]
```

If no path is provided, it scans the current directory.

### Example Projects
See the `examples/` directory for sample projects with generated READMEs demonstrating different project types.
