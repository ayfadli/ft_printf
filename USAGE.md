# README Generator - Usage Guide

## Overview
The `generate_readmes.py` script automatically generates README.md files for 1337/42 School curriculum projects. It scans directories, detects project types, and creates appropriate documentation.

## Features

### Project Type Detection
The script automatically detects three types of projects:

1. **C Projects**: Identified by the presence of `Makefile` or `.c` files
2. **Python Projects**: Identified by the presence of `.py` files  
3. **SysAdmin Projects**: Identified by folder names containing "born2beroot"

### Generated Content

Each README includes:
- **Title**: Project name from the folder
- **Description**: Contextual information about the project's role in the 1337 curriculum
- **Usage**: Specific instructions based on project type

#### C Projects
For C projects, the README includes:
- Compilation instructions using Makefile rules
- List of available `make` commands (all, clean, fclean, re, bonus)
- Running instructions

#### Python Projects  
For Python projects, the README includes:
- Instructions to run each Python script with `python3`
- Python version check command

#### SysAdmin Projects (Born2BeRoot)
For SysAdmin projects, the README includes:
- LVM configuration details
- SSH setup instructions
- UFW firewall configuration
- Verification commands

## Usage

### Basic Usage
Run the script from the command line:

```bash
python3 generate_readmes.py
```

This will scan the current directory and all subdirectories for projects.

### Scan Specific Directory
To scan a specific directory:

```bash
python3 generate_readmes.py /path/to/projects
```

### Examples

Generate READMEs for all projects in a repository:
```bash
python3 generate_readmes.py ~/1337/projects
```

Generate README for example projects:
```bash
python3 generate_readmes.py examples/
```

## Customization

### Adding New Project Descriptions
To add descriptions for new projects, edit the `get_project_description()` function in `generate_readmes.py`:

```python
descriptions = {
    'your_project': 'Description of your project in the curriculum.',
    # ... other projects
}
```

### Modifying README Templates
The README templates are generated by three functions:
- `generate_c_project_readme()` - for C projects
- `generate_python_project_readme()` - for Python projects  
- `generate_sysadmin_readme()` - for SysAdmin projects

Edit these functions to customize the generated content.

## Requirements
- Python 3.x
- No external dependencies required

## Notes
- The script will update existing README.md files
- Hidden folders (starting with `.`) are skipped
- Common non-project folders (`node_modules`, `venv`, `__pycache__`) are skipped
- The script is safe to run multiple times
